QUESTION-BY-QUESTION EXAM BLUEPRINT

Exact Structure, How to Write, and Traps to Avoid for Every Question

UIU EXAM PATTERNS

Question 1: HTML + JavaScript DOM & State Tracking (10 Marks)

The 6 Invariable Rules of Q1:

  1. HTML is minimal: 1 or 2 <input> tags + 1 <button> + 1 <label id="out"> placed directly below the button. No CSS needed!
  2. Memory must be outside function: Variables that remember state (let total = 0, count = 0, history = [];) MUST be declared outside the click function. If you put them inside, they reset to 0 every click!
  3. Input Parsing: Always use parseFloat(document.getElementById("id").value). Check if (isNaN(val) || val <= 0) return;.
  4. 4-Tier Classification Ladder: Use if ... else if ... else checking upper or lower bounds. Check highest limit first if using >=, or lowest limit first if using <=.
  5. The Signature Warning Trap: Every trimester has a condition like: "If the user makes more than N attempts/entries without reaching the goal, display [Warning]!" 
    if (count > 10 && total < GOAL) feedback += " Be cautious of frequent snacking!";
  6. Output to Label: Use document.getElementById("out").textContent = `...`; or .innerHTML.

Question 2: HTML Form + PHP Business Logic (10 Marks)

The 5 Invariable Rules of Q2:

  1. Two files: form.html (or index.html) and calculate.php. Every input MUST have a name="..." attribute (e.g. name="val1").
  2. Always define a PHP function: The question always says: "Write a PHP function that takes three inputs...". Do NOT write all code inline. Define function process($a, $b, $c) { ... return [...]; }.
  3. Ceiling Division for Whole Units: When booking venues, movie screens, or carrying battery modules, partial units are forbidden: 
    $unitsNeeded = ceil($demand / $capacity);  // 150 / 60 = 2.5 -> ceil() gives 3
  4. Empty Units & Wasted Money: 
    $emptySeats = ($unitsNeeded * $capacity) - $demand;
$wastedMoney = $emptySeats * $pricePerSeat;  // Check sample output table for multiplier!
  5. Target Comparison Exact Strings: 
    $d = $total - $target;
if ($d == 0)     $res = "Target met exactly (0 difference)";
elseif ($d > 0) $res = "Above target by $d";
else            $res = "Below target by " . abs($d);

Question 3: SQL Database Setup + PHP & MySQL Script (10 Marks)

The 5 Invariable Rules of Q3:

  1. Marks are split 50/50: 5 Marks for database.sql and 5 Marks for solution.php. Hand in BOTH files!
  2. Write database.sql immediately: Always start with CREATE DATABASE IF NOT EXISTS, USE, and DROP TABLE IF EXISTS so you can re-import freely.
  3. Standard Task 1 (Aggregation): SELECT category, COUNT(*) AS total FROM t GROUP BY category. If filtered by count: HAVING COUNT(*) > 1. (NEVER put COUNT in WHERE!).
  4. Standard Task 2 & 3 (Updates with compound conditions & caps): 
    -- Updating rating if salary < 40000 and not 'D'
UPDATE employee_final SET PerformanceRating = 'C' WHERE Salary < 40000 AND PerformanceRating != 'D';

-- Bonus 5000 only if resulting salary <= 60000 (Test the NEW value in WHERE!)
UPDATE employee_final SET Salary = Salary + 5000 WHERE Salary > 50000 AND (Salary + 5000) <= 60000;
  5. Standard Task 4 (Subquery / Category Average comparison): 
    SELECT name, category, price,
  CASE WHEN price > (SELECT AVG(price) FROM products t2 WHERE t2.category = t1.category)
       THEN 'Top Seller' ELSE 'Regular Seller' END AS seller_status
FROM products t1 ORDER BY price DESC;
